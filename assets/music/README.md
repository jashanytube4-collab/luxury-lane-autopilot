# Background music

Drop royalty-free tracks here (`.mp3`, `.wav`, `.m4a`, `.ogg`, `.flac`), commit and push. Each Short picks a
random track and a random section of it, and lowers the music automatically while the narrator speaks.

Recommended free source: **YouTube Audio Library** (YouTube Studio → Audio Library). Filter by
*Attribution not required*, moods *Dramatic / Inspirational / Bright*, genres *Cinematic / Ambient / Hip-hop*.
8–15 tracks give good variety.

If this folder has no tracks, a generated ambient pad is used instead. It works, but real tracks sound better.
